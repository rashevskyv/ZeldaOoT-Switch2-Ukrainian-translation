# The Legend of Zelda: Ocarina of Time (Nintendo Switch 2) — патчер українського перекладу

Патчер завантажує з цього репозиторію актуальні файли перекладу і вписує їх у копію вашого пакета `.nup`.
Ваш пакет патчер лише читає і не змінює. Українська мова стоїть на місці російської: у грі оберіть мову «Русский».

## Вимоги

1. Власний дамп гри: пакет `.nup` (title ID `0400486024DEC000`, версія 131072, з оновленням).
2. Вільне місце на диску: стільки ж, скільки займає пакет (близько 25 ГБ), і ще 1 ГБ.
3. Інтернет для завантаження файлів перекладу.
4. Windows: `OoT_Switch2_Patcher.exe`. macOS / Linux: Python 3.14+ і команда `python3 patcher.py`.

## Покрокова інструкція

1. Покладіть пакет `.nup` у теку `ISO` поруч із патчером.
2. Запустіть `OoT_Switch2_Patcher.exe` (або `python3 patcher.py`).
3. Патчер:
   - завантажить актуальні файли перекладу з GitHub;
   - перевірить title ID, версію і контрольні суми файлів, які замінює переклад;
   - якщо пакет інший, попередить і спитає, чи продовжувати;
   - запише новий пакет `ISO\<назва> (UA).nup` (це довго: копіюється весь пакет);
   - запише теку `ISO\<назва> (UA) PC\romfs` для ПК-портів.
4. Після напису «Готово!» натисніть Enter.

## Результат

- `<назва> (UA).nup` — пакет гри з українським текстом на місці російського.
- `<назва> (UA) PC\romfs` — лише змінені файли для ПК-портів:
  - Hookshot: запускайте з `HOS_FS_OVERLAY=<шлях до цієї теки romfs>` і `HOS_LANGUAGE=ru`;
  - NX2navi: покладіть теку `<назва> (UA) PC` у теку модів (`mods_dir` у `nx2navi.ini`), `lang = ru`.
