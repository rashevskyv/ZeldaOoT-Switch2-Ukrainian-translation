# The Legend of Zelda: Ocarina of Time (Nintendo Switch 2) — патчер українського перекладу

Патчер завантажує з цього репозиторію актуальні файли перекладу і вписує їх у копію вашого пакета `.nup`.
Ваш пакет патчер лише читає і не змінює. Українська мова стоїть на місці російської: у грі оберіть мову «Русский».

## Вимоги

1. Власний дамп гри: пакет `.nup` (title ID `0400486024DEC000`, версія 131072, з оновленням).
2. Вільне місце на диску: стільки ж, скільки займає пакет (близько 25 ГБ), і ще 1 ГБ.
3. Інтернет для завантаження файлів перекладу.
4. Windows: `OoT_Switch2_Patcher.exe`. macOS / Linux: Python 3.14+ і команда `python3 patcher.py`.

## Покрокова інструкція

1. Покладіть пакет `.nup` у теку `ISO` поруч із патчером.
2. Запустіть `OoT_Switch2_Patcher.exe` (або `python3 patcher.py`).
3. Патчер:
   - завантажить актуальні файли перекладу з GitHub;
   - перевірить title ID, версію і контрольні суми файлів, які замінює переклад;
   - якщо пакет інший, попередить і спитає, чи продовжувати;
   - запише новий пакет `ISO\<назва> (UA).nup` (це довго: копіюється весь пакет);
   - запише теку `ISO\<назва> (UA) PC\romfs` для ПК-портів.
4. Після напису «Готово!» натисніть Enter.

## Результат

- `<назва> (UA).nup` — один пакет для консолі та емуляторів.
- `<назва> (UA) PC\romfs` — лише змінені файли для ПК-портів (NX2navi, Hookshot). Копія пакета не створюється.

### Longshot

Longshot (https://longshot.magicbean.dev/install/) збирає гру з вашого пакета `.nup` і розпаковує її у свою теку.
Перезбирати пакет для Longshot не треба: переклад можна записати прямо в гру, яку Longshot уже розпакував.

1. Зберіть гру в Longshot Launcher зі свого пакета, як зазвичай.
2. Запустіть патчер. Він сам шукає Longshot (у теці лаунчера є `builds.json` зі списком зібраних ігор).
   Якщо Longshot стоїть у режимі portable, патчер спитає теку, де лежить `LongshotLauncher.exe`, і запам'ятає її.
3. Патчер покаже теку гри, наприклад `LongshotLauncher-data\builds\rc\romfs`, і спитає, чи писати туди переклад.
4. Після «y» він:
   - кладе оригінали файлів, які замінює, у теку `romfs_original_ua_backup` поруч (лише перший раз);
   - записує файли перекладу в `romfs`;
   - ставить мову гри `ru` у `language.txt` і в налаштуваннях лаунчера (українська стоїть на місці російської).
5. Далі патчер питає, чи збирати ще й пакет `.nup` (для консолі, NX2navi або Hookshot). Для Longshot він не потрібен.

Якщо Longshot перезбере гру (наприклад, після свого оновлення), запустіть патчер ще раз.

### NX2navi

Патчер запитає, чи налаштувати NX2navi, і попросить теку встановленої гри (де `game\nx2navi.ini`). Лише після вашого «y» він ставить `lang = ru` і `mods_dir` на теку `ISO`. Старий ini зберігається як `nx2navi.ini.bak`. Теку `(UA) PC` NX2navi бачить як мод. Копіювати її не треба.

## Оновлення та повторна збірка

- Щоб оновити переклад, запустіть патчер ще раз. Патчер перевіряє GitHub:
  - якщо версія та сама, він пише «Вже актуальна версія» і нічого не змінює;
  - якщо є новіша версія, він показує, що нового, і оновлює результат. Де можна, змінюються лише змінені файли.
- Патчер сам оновлюється з GitHub, коли там новіша версія. Стара копія лишається як `patcher.py.bak`.
- Повна збірка з нуля: запустіть `Перепатчити з нуля.bat` поруч із `.exe`. Він видаляє старий результат і кеш, потім збирає з вашого оригіналу. Дамп не змінюється.
- Кеш завантаженого перекладу: `ISO\.ua_cache`. Це один zip (близько 1–15 МБ), можна видалити.
- Без інтернету патчер зупиняється з повідомленням. Він не використовує файли, що лежать поруч.
